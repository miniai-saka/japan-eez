# 海域と領空の判定

このModは、Minecraftの海岸線に対して、領海・EEZ・大陸棚・領空を設定・表示するためのものです。現実の日本の地理や境界を再現するデータは含んでいません。

## 距離の起点

海面の高度にある生成時のバイオームを使い、陸・砂浜と海洋バイオームの境目を海岸線として扱います。砂浜は海岸側に含め、河川や湖は海洋として扱いません。

距離は、海岸線から水平に測ります。初期設定では1海里を1ブロックとして、領海は12、EEZは200、延長大陸棚の上限は350ブロックです。

手動で測量基準線を引いた場合も、海域の距離の起点は、この自動取得する海岸線です。

## EEZと大陸棚

EEZは、海岸線から200ブロック以内の海です。通常の海・深い海の両方を含みます。

大陸棚は、海岸から通常の海が続いている部分です。通常の海を上下左右にたどって、海岸につながるかを調べます。深い海は大陸棚に含めず、深い海を経由して通常の海のつながりを判定することもありません。

延長大陸棚を有効にすると、200ブロックを超えた先も通常の海が続いている場合、その部分を最大350ブロックまで大陸棚に含めます。延長されるのは大陸棚の範囲です。EEZの範囲は変わりません。

延長を無効にした場合は、通常の大陸棚を200ブロック以内で判定します。

## 領有者と通知

海域の所有者は、最寄りの海岸側が確定領域内にあれば、その領域の所有者です。それ以外は`defaultOwner`を使います。初期値は「日本」です。

陸地の領有通知は、自分で作成して確定した領域について表示します。重なった領域では、先に登録した領域を優先します。

EEZと延長大陸棚の進入通知は、地下下限から海面付近までで判定します。領域や所有者が変わったときにタイトルを表示するので、範囲内に立っている間、同じ通知を繰り返すことはありません。

「漁業・採掘可能」などの文言は領域の案内です。アイテムの使用や採掘を許可・禁止する保護処理は行いません。

## 領空と高度

領空は、設定した領有地と領海の上に適用します。EEZと延長大陸棚の上空は、領空として扱いません。

領有地では、現在地の地表の高さも見て、領域と領空の通知を切り替えます。領空の上限は`airspaceTopY`です。領域に指定した上限とは独立しており、領空上限を超えた位置は領空外になります。

枠線は、領海・EEZ・大陸棚では地下下限から海面まで、領空では海面付近から領空上限まで表示します。起伏に沿った地表面の立体モデルではなく、境界の外周と高度を示す表示です。

## 調査と表示の精度

海岸線を調べるときに、遠方のチャンクを新しく生成することはありません。生成時のバイオームを参照するため、海を埋め立てたり、`/fillbiome`で変更したりしても、判定には反映しません。

初期の調査・枠表示は4ブロック間隔です。海岸線を格子で表すので、枠には段差や数ブロックの丸めが生じます。通知に使う距離は、その格子上の海岸線から、プレイヤーの実際の座標まで測ります。Minecraft本体のバイオーム補間表示と一致しない場合もあります。

枠を細かくしたい場合は、`surveyStep`を1または2に変更できます。ただし、調査時間とメモリ使用量が増えます。まずは初期値で使い、表示を確認しながら調整してください。

## 表示範囲と更新

初期の表示半径は128ブロックです。最初の調査や、移動・設定変更後の更新には時間がかかる場合があります。初期の同期周期は40tick、通常の進行速度で2秒です。

基準点は周辺の最大1024個、枠は最大8192線分まで送ります。非常に複雑な海岸では、一部の表示が省略される場合があります。

大陸棚の連続性は、周辺の調査範囲内で評価します。遠くへ大きく迂回して海岸につながる地形は、除外される場合があります。

各設定の変更方法は、[操作と設定](usage.md#設定項目)を参照してください。
